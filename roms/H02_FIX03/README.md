# H02 FIX03 — builds de trabajo

Las ROMs son dos variantes del mismo fuente: una híbrida MSX2/turboR y otra exclusiva turboR (R800). Ambas son compilaciones experimentales **sin validación visual completa**.

**Errores conocidos:** scroll por tiles/trompicones, despegue y transición de nodriza, estrellas, CAUTION/cronología (paridad sin confirmar). No tratar como versión final. Preservar H01 como baseline de seguridad.

Cargar como cartucho ASCII16. Para turboR seleccionar Panasonic FS-A1ST/FS-A1GT con BIOS válidas.
